# Инструкция по созданию суперпользователя

## Создание суперпользователя для админ-панели

Для доступа к админ-панели Django необходимо создать суперпользователя.

### Команда для создания:

```bash
cd c:\Projects\Jewelry\backend
.\venv\Scripts\activate
python manage.py createsuperuser
```

### Пример данных для входа:

```
Username: admin
Email: admin@jewelry.local (можно оставить пустым)
Password: admin123 (введите надёжный пароль!)
Password (again): admin123
```

**Важно:** После ввода команды система попросит ввести:
1. Имя пользователя (username)
2. Email (можно пропустить)
3. Пароль (при вводе символы не отображаются — это нормально)

### Доступ к админ-панели:

После создания суперпользователя и запуска сервера:
- **URL:** http://localhost:8000/admin/
- **Логин:** ваше имя пользователя
- **Пароль:** ваш пароль

## Что доступно в админ-панели:

- **Products (Изделия)** — добавление, редактирование, удаление украшений
- **Categories (Категории)** — управление категориями (кольца, серьги и т.д.)
- **Sets (Сеты)** — создание наборов украшений
- **Product Images** — загрузка фотографий для каждого изделия
- **Orders (Заказы)** — управление заказами (будет реализовано)

## Загрузка фотографий:

При добавлении товара через админ-панель:
1. Создайте продукт
2. Сохраните его (кнопка "Save")
3. Внизу страницы появится секция "Product images"
4. Добавьте фотографии, отметьте одну как "Is primary" (основная)
