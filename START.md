## 🔧 Управление проектом

### Остановка серверов

**Backend:**
```bash
# Найдите процесс на порту 8000
netstat -ano | findstr :8000
# Завершите процесс (замените PID на ваш)
taskkill /F /T /PID <PID>
```

**Frontend:**
```bash
# Найдите процесс на порту 3000
netstat -ano | findstr :3000
# Завершите процесс
taskkill /F /T /PID <PID>
```

### Запуск серверов заново

**Backend (Терминал 1):**
```bash
cd c:\Projects\Jewelry\backend
.\venv\Scripts\activate
python manage.py runserver
```

**Frontend (Терминал 2):**
```bash
cd c:\Projects\Jewelry\frontend
npm start
```

## 👤 Создание администратора

Для доступа к админ-панели создайте суперпользователя:

```bash
cd c:\Projects\Jewelry\backend
.\venv\Scripts\activate
python manage.py createsuperuser
```

Введите:
- Username: admin
- Email: (можно пропустить)
- Password: (надёжный пароль)

После создания войдите на: http://localhost:8000/admin/

## 📸 Добавление фотографий товаров

1. Войдите в админ-панель
2. Перейдите в раздел "Products" → выберите товар
3. Внизу страницы найдите секцию "Product images"
4. Нажмите "Add Product Image"
5. Загрузите файл изображения
6. Отметьте "Is primary" для главного фото
7. Сохраните

Фотографии сохраняются в `backend/media/product_images/`

## 📊 API Endpoints

| Endpoint | Описание |
|----------|----------|
| GET /api/categories/ | Список категорий |
| GET /api/products/ | Товары (с пагинацией) |
| GET /api/products/?category=1 | Товары категории |
| GET /api/products/?min_price=10000&max_price=50000 | Товары по цене |
| GET /api/products/<id>/ | Детали товара |
| GET /api/sets/ | Список наборов |
| GET /api/search/?q=кольцо | Поиск |

## 📞 Поддержка

При возникновении проблем:
1. Проверьте, что оба сервера запущены
2. Проверьте порты 8000 и 3000 (netstat -ano | findstr :8000)
3. Перезапустите серверы
4. Очистите кэш браузера
