# 💎 LUXEJEWELS — Интернет-магазин ювелирных изделий

Современный интернет-магазин роскошных ювелирных изделий, созданный в стиле **"The Digital Atelier"**.

## 🌐 Сайт доступен

- **Frontend:** http://localhost:3000
- **Backend API:** http://localhost:8000/api/
- **Админ-панель:** http://localhost:8000/admin/

---

## ✨ Особенности дизайна

Проект следует философии **"ATELIER"** — цифрового бутика высокой моды:

- **Hero секция** на весь экран с драматичными изображениями
- **Bento Grid** галерея категорий с асимметричной компоновкой
- **Минималистичная навигация** с элегантными шрифтами
- **Адаптивный дизайн** для телефонов, планшетов и десктопов
- **Плавные анимации** и переходы

### Цветовая палитра
- `surface` (#faf9f6) — тёплый белый фон
- `primary` (#000000) — глубокий чёрный
- `secondary` (#775a19) — мягкое золото
- `surface-container` (#efeeeb) — контейнеры

### Типографика
- **Noto Serif** — заголовки и акценты
- **Manrope** — основной текст

## 📦 Каталог

- **40 украшений** с реальными фотографиями
- **5 категорий**: Кольца, Серьги, Браслеты, Кулоны, Цепочки
- **8 готовых сетов** (наборов) со скидками
- **Фильтрация** по категории, материалу, цене
- **Поиск** по названию и описанию

---

## 🛠 Технологии

### Backend
- **Django 6+** — веб-фреймворк
- **Django REST Framework** — API
- **SQLite** — база данных
- **Pillow** — обработка изображений

### Frontend
- **React 18** — UI-библиотека
- **Tailwind CSS** — стилизация
- **React Router v6** — маршрутизация
- **Axios** — HTTP-клиент

## 🚀 Быстрый старт

### Вариант 1: Docker (рекомендуется)

```bash
# Production режим
docker-compose --profile production up -d --build

# Development режим
docker-compose --profile development up -d --build
```

**Доступ:**
- Frontend: http://localhost:3000
- Backend API: http://localhost:8000/api/
- Admin: http://localhost:3000/admin/

**Создание суперпользователя:**
```bash
docker-compose exec backend python manage.py createsuperuser
```

📖 **Подробная инструкция:** см. [DOCKER.md](DOCKER.md)

### Вариант 2: Локальная разработка

### 1. Backend (Django)

```bash
cd c:\Projects\Jewelry\backend
.\venv\Scripts\activate
python manage.py runserver
```

### 2. Frontend (React)

```bash
cd c:\Projects\Jewelry\frontend
npm start
```

### 3. Создание администратора

```bash
cd c:\Projects\Jewelry\backend
.\venv\Scripts\activate
python manage.py createsuperuser
```

## 🔌 API Endpoints

| Endpoint | Описание |
|----------|----------|
| `GET /api/categories/` | Список категорий |
| `GET /api/products/` | Товары (с пагинацией) |
| `GET /api/products/<id>/` | Детали товара |
| `GET /api/sets/` | Список наборов |
| `GET /api/featured-products/` | Рекомендуемые товары |
| `GET /api/search/?q=...` | Поиск товаров |
